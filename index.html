A bit about me

No grand mission statement here — just a developer who enjoys making things work a little better than they used to.

  • 🗺️

    Geospatial explorer

    I spend a lot of time around LuciadRIA, WFS, and OGC APIs — building tools that make maps and 3D data easier to work with.

  • ♻️

    Serial library reviver

    Several of my packages are modern forks of great React libraries that got abandoned — updated, patched, and kept alive for React 18 & 19.

  • 🧩

    Tiny-tool addict

    If I do something manually twice, it becomes a small npm package by the third time. base62str exists because of exactly this.

  • 🕹️

    Curiosity-driven builder

    Dual joysticks on an iPad, device-orientation hooks, gamepad support for React — some projects exist purely because "can this be done?"

  • ☕

    Runs on coffee

    Every commit after 3pm should probably be reviewed twice. I stand by all of them anyway.
